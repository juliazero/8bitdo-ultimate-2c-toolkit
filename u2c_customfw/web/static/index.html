Firmware Details

      
Problem Report

        
Creates a text you can attach to a bug report, with the device IDs, the firmware's state and the latest log lines. It never includes your controller's address or its Bluetooth pairings.

        

      
Battery Log

        
This is stored battery history, separate from the current battery percentage above. With Processor rest installed, the controller records its voltage and battery percentage once a minute while running on battery, including over Bluetooth or 2.4 GHz. You do not need to keep this app open.

        
To export the history as a CSV file, connect the controller directly by USB, in normal or update mode. Export is unavailable over Bluetooth or through the dongle. On Windows, if the Xbox 360 USB mode exposes input only, use update mode (hold LB + RB while connecting USB).

        
The history survives power-offs and holds about 270 hours of battery use across multiple sessions. When full, recording stops. Exporting does not clear it.

  • The controller's firmware version can't be identified, so there is no way to check that 1.09 is right for it.
    •

Help

    

    

  
Out of the box, macOS and most Mac games don't recognise the 8BitDo Ultimate 2C Wireless as a standard controller. This app changes the controller's firmware (the software inside it) so that they do. It only works with firmware 1.09.

  
1. Back Up

  
Saves a full copy of the controller's memory on this Mac. It changes nothing on the controller. It is required before the first change, so you can always restore the controller exactly as it was. Backups are kept on this Mac, in ~/Library/Application Support/u2c-customfw.

  
Update Mode

  
The controller can only receive new firmware in update mode. By cable, the app puts it there by itself to install or restore, and restarts it afterwards. Check First reads the controller by cable and leaves it running. If a write is interrupted, the controller stays in update mode, and Restore still works there.

  
To put it in update mode yourself, for example if the app can't, turn it fully off, then hold LB + RB while plugging in the cable. The small light below the Home ring will blink white. To leave update mode without the app, unplug the cable and hold Home for about 12 seconds, until it turns off.

  
Check First

  
Runs every check without changing anything: that this is the same controller as in your backup, that its firmware is one the app knows, and that the new firmware is complete.

  
3. Restore

  
Restores your backup, or 8BitDo's original firmware 1.09. Use it if something doesn't work, or to use 8BitDo's own apps and updates again.

  
After Installing

  
The app restarts the controller by itself. If you changed a Bluetooth tweak, remove the controller from Bluetooth settings and pair it again, because macOS remembers how a device introduced itself the first time.

    

    

  
2. Tweaks

  
    
    
  • XInput mode over Bluetooth. Uses an Xbox-compatible Bluetooth identity, shown as (X), so supported games and systems can recognise the controller. Set a custom name under the switch, up to 27 characters. Remove the old Bluetooth pairing and pair again after a profile or name change.
    • 
    
  • Bluetooth X / D mode selection. With the rear switch on Bluetooth, hold X or B and press Home to start in XInput or D-input. While on, hold Home + X or B for 3 seconds to restart in that mode. Home alone restores the last choice. Each profile has its own Bluetooth identity and pairing. Over 2.4 GHz, switching to D-input requires the dongle D-input tweak.
    • 
    
  • Switch 2 Pro Controller mode (Y). Adds a separate Bluetooth profile using the Pro Controller 2 protocol. Hold Y and press Home from off, or hold Home + Y for 3 seconds while on. Home alone restores the last X, D or Y mode. Switch2Connect on Windows performs its own pairing; do not pair Y through Windows Bluetooth Settings. Y supports buttons and sticks; vibration, motion controls, NFC and audio are unavailable.
    • 
    
  • Rumble over Bluetooth. Enables game vibration in Bluetooth X and D profiles. D requires Bluetooth X / D mode selection. Remove and pair the profiles again after installation so the system reads the updated capabilities. Y vibration is not supported.
    • 
    
  • Long rumble over Bluetooth. Honours the repeat count in vibration requests. Long Android effects can continue beyond 2.55 seconds; a new request or disconnection stops the effect. Requires Rumble over Bluetooth.
    • 
    
  • Xbox 360 controller over cable. Uses an Xbox 360 identity for the USB XInput profile, including macOS compatibility. Set a custom USB name under the switch, up to 38 characters. This does not change the USB D-input profile.
    • 
    
  • USB XInput / D-input switching. While USB is connected, hold Home + B for 3 seconds for D-input or Home + X for XInput. Release Home between changes. The controller remembers the selected USB mode. Mode changes pause during firmware operations.
    • 
    
  • Dimmer LEDs. Slightly lowers the brightness of the controller's three lights. It is subtle: to really change the ring around the Home button, use Home Ring in the Settings tab.
    • 
    
  • Battery alerts. The ring blinks slowly while charging and quickly at 6 % or less, about 2 hours before the end, even if you turned it off. The motors give one short pulse when charging starts, one long pulse when it completes, and two short pulses at 1 %, about 30 minutes before the end, again every 5 minutes. It needs the Home ring's code.
    • 
    
  • Controller settings. Adds what the Settings tab changes: sticks, triggers, L4 and R4, vibration, power and button remapping. With everything at its default, the controller runs its original code for these. It needs the Home ring's code.
    • 
    
  • Connection and idle fixes. Stick movement counts as activity, dropped connections get their full reconnection time, and unplugging USB restarts the wireless connection. Firmware updates over Bluetooth are disabled.
    • 
    
  • Processor rest. Over Bluetooth on battery, the controller's processor normally runs without a pause. With this tweak it stops for up to a millisecond at a time while it waits for the next exchange with the computer, which may make the battery last longer. A watchdog also restarts the controller if it ever stops responding. Since version 1.1, it also keeps the battery log you can save in the Diagnostics tab.
    • 
    
  • Finer stick movement. The firmware ignores small stick changes, which makes slow movement advance in small jumps. This lowers that limit to just above the noise measured on one controller. A stick held still away from the centre may still move by one step now and then, which is why it's off by default.
    • 
    
  • Faster button reading. The controller reads its buttons and triggers every 5 ms. This reads them every 2.5 ms, so a press reaches the game about 1.25 ms sooner on average. Holding Home and turbo keep their usual timing. The firmware has no other debounce, so a worn button could occasionally register twice. That's why it's off by default.
    • 
    
  • Faster Bluetooth input. Over Bluetooth the controller sends its input at the moments the computer sets for it. Every install asks for one every 12.5 ms. This asks for one every 7.5 ms, the shortest Bluetooth allows, so input can arrive up to 5 ms sooner where the system follows the request, as Android does. macOS keeps its own 15 ms. The controller wakes more often, so its battery runs down sooner. That's why it's off by default.
    • 
  

  
Every install also gives a battery level based on a discharge measured on one controller, so the percentage follows the time left more closely. The original firmware counts down evenly by voltage, so it showed half with nearly three quarters of the time left, and 1 % for the last hours. Times can differ from one controller to another, and with games that vibrate a lot.

  
Every install also asks the computer for a 12.5 ms Bluetooth connection interval, instead of the 7.5 ms the original firmware asks for, unless Faster Bluetooth input is on. macOS keeps its own 15 ms, and other systems may follow the request.

  
The Home ring's code is installed with any tweak that needs it. Installing keeps the ring's level as it is, and you change it in the Settings tab.

  
The tweaks are always added to 8BitDo's original firmware 1.09, taken from your backup or downloaded from 8BitDo, so the result is always a known, checked firmware.

    

    

  
Settings

  
This tab changes the controller while it's connected by cable, once the Controller settings tweak is installed. A change applies at once and is lost when the controller turns off or restarts, unless you press Save to Controller. Reset to Defaults… puts these settings back, apart from the Home ring and the calibration, and works without pressing any buttons on the controller.

  
Restoring the firmware doesn't erase them. The original firmware ignores most of them, and they apply again if you install the tweak again, but it does keep using the L4 and R4 mappings and the dead zone switch, because those are its own. Use Reset to Defaults… first if you want those gone. While this tab is open, as with the controller test, Home doesn't open Apple Games.

  
Home Ring sets how bright the ring around the Home button is while the controller is connected. Normal keeps its usual brightness, and the percentages are how much of the time the light is on, not how bright it looks. It still blinks while searching or pairing, at its usual brightness, and settles at your level once connected. Off keeps it dark while connected. A change applies at once, over Bluetooth or by cable, without installing anything, and Save Ring Level keeps it after the controller turns off. L4 + R4 on the controller also change it.

    

    

  
Diagnostics

  
This tab helps you check how macOS sees the controller, and gather information if something goes wrong.

  
Controller Test shows what macOS's GameController reports, which is what a game gets, including the battery when macOS provides it. Press each control to see it light up, and use the buttons to make the controller vibrate. "Vibrate Like a Game" uses the same path as native games, and "Direct Report" goes straight to the controller, so if only the direct report vibrates, the firmware isn't the problem. The first time you press the Home button in this test, macOS may ask for your permission to let the app receive it. If you allow it, Home won't open Apple Games while this tab is open. This test is only available in the Mac app.

  
The controller also has its own option for the sticks: holding − (Select) and + (Start) together for about 4 seconds switches a 14 % dead zone on the sticks on and off. The controller buzzes once when it turns on and twice when it turns off, and it remembers the setting. It's part of 8BitDo's firmware.

  
Firmware Details shows what the app read from the controller, including where the version came from and whether a firmware update is pending.

  
Create Problem Report collects the controller's state and the last task's log for a bug report. It never includes the controller's address, its Bluetooth pairings or your backup.

  
Save Battery Log reads, by cable, the log that firmware installed with Processor rest keeps: once a minute on battery, the battery's voltage and level, whether it was connected over Bluetooth and whether it was vibrating. Nothing is written while the controller has a cable, and the log stays through power-offs, so it covers a whole charge until the controller turns itself off. It's saved as a CSV file next to your backups, and holds nothing else about the controller.

  
Install Firmware 1.09 Anyway… is only for a controller whose firmware can't be identified. It erases the firmware and installs 8BitDo's original 1.09 without being able to check beforehand that it's right for the controller, so use it only if Restore doesn't work.

    

    

  
2.4 GHz Dongle

  
The app also works with the Ultimate 2C's 2.4 GHz dongle on firmware 1.03. Plug it in with the controller off, so it's on its own, and the Firmware tab shows its firmware and its tweaks.

  
    
    
  • Xbox 360 controller over 2.4 GHz. With the controller connected through it, the dongle presents itself to the Mac as a wired Xbox 360 controller, which macOS and its games recognise. It also reports a different version number from the controller by cable, so the app can tell the two apart. You can also give it its own name in X-input, in the box under the switch, up to 38 characters, such as “8BitDo Ultimate 2C (Xbox 360)”, instead of 8BitDo's “8BitDo Ultimate 2C Wireless Controller”, which the controller by cable has too. If you leave it empty, it keeps the name it has.
    • 
    
  • D-input mode with B + Home. Brings back the D-input mode of the dongle's first firmware, 1.00, which 1.03 dropped. With the controller set to D-input, the dongle presents itself as a generic gamepad (2dc8:301c), which Android handles natively, also on TVs that don't support Xbox controllers. To set it, unplug the controller's cable, hold B and Home until the controller turns off, then hold B while you press Home to turn it on. It stays in D-input until you turn it off with X and Home held; X-input is the dongle's usual mode, with or without the Xbox 360 tweak. In D-input the app doesn't see the dongle while the controller is on. In D-input the dongle can have a name of its own too, up to 36 characters, such as “8BitDo Ultimate 2C (D-input)”, so the two modes are told apart in lists such as macOS's Game Controllers settings. If you leave it empty, it uses the X-input name, as 8BitDo's firmware does.
    • 
  

  
Back Up saves the dongle's whole memory on this Mac. You need a backup of the dongle before installing or restoring. The dongle has no buttons, so the app puts it in update mode by itself when it writes, checks it there against your backup before anything is erased, writes only its firmware, and restarts it. Check First reads the dongle without changing it.

  
Restore puts back your backup, or 8BitDo's original firmware 1.03, made from your backup and checked against its known checksum. If a write is interrupted, the dongle stays in update mode, the app says so, and Restore still works.

  
With the controller connected through the dongle, the app shows the dongle's firmware but doesn't change it. Turn the controller off first. The controller's own firmware can only be read by cable.
